# customer_churn_analysis
Customer churn refers to customers discontinuing their services with a company. Predicting customer churn helps organizations identify customers who are likely to leave and take appropriate actions to improve customer retention.

This project focuses on analyzing customer data and building a Machine Learning model to predict customer churn. The project includes data preprocessing, exploratory data analysis (EDA), data visualization, feature engineering.

The project was developed as part of my IBM Internship.
